## 一、研究设计速览（v4.0 现行）

| 要素 | 内容 |
|------|------|
| 设计 | 前瞻性、单中心、观察性、单臂、自身前后对照 |
| 样本 | 共同母队列统一计划招募 40 例（24/(0.80×0.85×0.90)≈39.2 向上取整），争取 ≥24 个影像 QC 合格配对；不按中期效应量或 P 值提前停止 |
| 扫描 | 术前 1–7 天（8–14 天记偏离仅入敏感性）+ 术后 30±7 天：3D-T1 + rs-fMRI（240 volumes/8 min）+ DTI（30 方向单壳 b=1000；AP 主序列 + PA 反向 b0）；CNV-FLAIR-DTI 为 go–no–go 通过后的可选探索序列 |
| 临床锚点 | ΔNRS7d：两次 MRI 前各连续 7 个日历日记录"每日最重发作 NRS"，至少 5/7 天有效；正值表示疼痛改善，7/7 完整日记作敏感性分析 |
| 主要影像终点 | 右 mOFC 先验 ROI（6 mm 球形，MNI 6,57,−9，雷博 C6 簇）Δz-fALFF |
| 关键次要验证 | M2：ΔmOFC ↔ ΔNRS7d（固定检验顺序：Spearman → ΔFD 校正模型）。M3 为预设敏感性分析（非推断性）：在 M2 基础上加入 ΔSLI，描述 β1 及其不确定性变化，不设 H3、不解释直接效应/中介效应/因果独立性 |
| 次要 | 全脑 ΔfALFF（ΔFD 协变量置换 GLM + TFCE-FWE）、2 条预设 mOFC 中心 FC 边（前岛叶/杏仁核，不设 mOFC–ACC）、全脑 TBSS（预先接受阴性） |
| 探索 | CNV-DTI（预试验 go–no–go 门控）、1 月指标 vs 3/6/12 月远期结局（不做预测模型） |
| 明确不做 | 预测建模/列线图、回顾性队列、高维机器学习、麻木轨迹/脑-麻木/感觉通路分析、健康对照、多时间点 MRI（见开题报告"研究边界"） |
| 质控红线 | mean FD>0.2 mm 剔除；感觉检查按固定 V1/V2/V3 位点与器械、顺序、重复次数计 SLI（κ≥0.70、ICC≥0.75 可靠性考核）；7 天日记、感觉 SOP、分析集、DTI/CNV 协议、ROI/FC manifest 与 QC 规则须在首例正式入组前签字冻结 |

**核心主线逻辑**（开题答辩就守这一页）：
```
PBC（镇痛改善 ＋ 面部感觉改变并存）
  → 术前/术后 1 月 rs-fMRI + DTI（感觉检查按冻结 SOP 执行）
  → 唯一主要终点：右 mOFC Δz-fALFF（回答"脑功能是否改变"）
  → 关键次要分析：ΔmOFC ↔ ΔNRS7d（固定检验顺序）
  → 预设敏感性分析：再加入 ΔSLI（非推断性）
  → 仅在主要终点和关键关联均获支持时，使用"镇痛相关脑功能变化"表述
```
